# 🧩 三、逐模块“衔接式”详细说明（核心）

# 3.1 参考轨迹生成（连接起点）

## 🎯 目标

为后续模仿学习提供**高质量、可控、多样化的 jump reference**

------

## 方法

基于 的 Motion Matching：

[
i^* = \arg\min_i ||x_t - x_i||^2
]

生成：

```text
D_ref = {q_t^{ref}, c_t}
```

------

## 🔗 关键衔接（必须写清楚）

👉 **这些 reference 是后面 BeyondMimic 的监督信号**

也就是说：

> Motion Matching ≠ 控制
> Motion Matching = 数据生成器

------

# 3.2 BeyondMimic 训练 Teacher（第一阶段学习）

------

## 🎯 目标

学习一个**能够精确跟踪参考轨迹的专家策略**

[
\pi_E(a_t | s_t, q_t^{ref})
]

------

## 为什么用 BeyondMimic？

因为：

- jump 是高动态任务
- RL 从零学 → 极难
- imitation → 提供 strong prior

------

## 输入

- 当前状态 (s_t)
- reference motion (q_t^{ref})

------

## 输出

- joint target

------

## Reward（核心）

[
r = r_{tracking} + r_{stability} + r_{smooth}
]

------

## 🔗 关键衔接（非常重要）

👉 Teacher 的本质：

> **“局部最优的 tracking controller”**

但问题：

- 只会跟踪
- 不会决策
- 不具备泛化

👉 所以必须进入下一步：

➡️ **蒸馏 + RL**

------

# 3.3 Teacher Rollout 数据收集（过渡步骤）

------

## 🎯 目标

构建蒸馏数据集：

```text
D_teacher = {(s_t, a_t^E, c_t)}
```

------

## 为什么需要这一步？

因为：

- Teacher 输入包含 reference（测试时不可用）
- Student 不能依赖 reference

👉 所以要：

> 用 Teacher 生成“行为标签”

------

# 3.4 蒸馏 Student（第二阶段学习）

------

## 🎯 目标

学习一个**不依赖 reference 的统一策略**

[
\pi_S(a_t | s_t, c_t)
]

------

## 输入变化（关键）

| Teacher           | Student         |
| ----------------- | --------------- |
| state + reference | state + command |

------

## Loss（核心）

[
L_{DAgger} = ||a_t^S - a_t^E||^2
]

------

## 🔗 关键衔接（必须讲清）

👉 蒸馏的作用：

> 把“tracking skill” → 转换为“command-driven control”

但问题：

- imitation 是局部的
- 不考虑任务成功（比如跳不远）

👉 所以还不够

------

👉 **优化任务成功率 + 泛化能力**
